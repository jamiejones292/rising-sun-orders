# Design prototypes

Clickable prototypes agreed with the pub before the real build. They are the visual
reference for the app: colours, type, layout, wording and behaviour. They use example
data only and are not connected to anything.

| File | What it shows | Live copy |
|---|---|---|
| `customer-prototype.html` | Customer ordering: welcome, menu, basket, table 1–25, Apple Pay / Google Pay, tracking, email receipt | https://claude.ai/artifact/DXVnscYc2ryzMkXxSoW9q2 |
| `bar-screen-prototype.html` | Bar iPad: password sign-in, live order cards, tick-off page, Order Fulfilled, small admin section | https://claude.ai/artifact/WrRCNczboN5dNLcjJMrdqk |
| `admin-prototype.html` | Full admin: drinks and stock, categories, tables and QR code, orders and refunds, reports, staff, settings | https://claude.ai/artifact/7yZqCaA13Hv9ZUyB87QtdG |
| `logo.jpg` | Logo trimmed for screens (900 × 842) | |
| `logo-original.jpg` | Original logo artwork as supplied (2000 × 2000) | |

The HTML files were written for Claude's artifact viewer, which adds the page wrapper
(`<!doctype>`, `<head>`, viewport tag). To open one directly in a browser, use the demo
build on drinksorder.app instead, or wrap it in a basic HTML page.

The passwords inside the prototypes (`risingsun`, `gerwyn / admin`) are demo-only and are
never used by the real app.
